# 2026-11-08 軽い進め方を足す

## 背景

R-004（Task 1つ）は、効率に寄せる前で約25分・約33万トークンかかった。小さい直しや文言まで Worker と Reviewer を通すと、手間が中身に見合わない。

## 決めたこと

- 小さい直し・文言・触るファイルが1〜2つ・見た目の調整は、**軽い進め方**：Boss に一言伝えてから Orchestrator が本体で直接作り、`.claude/harness.json` の checks を1回流してコミットする。Review はなし、Task のファイルも作らない。
- 触るファイルが3つ以上・データ・課金・ログイン・サーバー・条件がぶつかりやすいもの、または迷ったときは、今の進め方（Worker と Reviewer）。
- 前の決まり「Orchestrator は、Worker に任せられる実装を自分では行わない」は、この区分けに置きかえた。

## 変えなかった守り

Guard・秘密の値・外へ出る操作の Approval Gate・禁止のこと。今の進め方の Merge には、Review の合格と検査の記録が要ること。

## まだ確かめていないこと

- 軽い進め方の1件目で、時間とトークンを測る。
