# 上限と停止条件

値が空欄のものは「上限 0」として扱い、その操作は Approve 区分として1回ずつ確認します。値は Boss が決めます。

## 上限

| 項目 | 上限 | 数え方 | 超えたとき |
|---|---|---|---|
| 同時に動かす Worker | **3**（Reviewer は別に数える） | 同時に動いているサブエージェント | 新しく起動しない。触るファイルが重なるものは同時に動かさない |
| 停止条件：同じ失敗 | **3 回** | 同じ Task で、同じ理由の失敗が続いた数 | 止めて Boss に報告する |
| 停止条件：Review の不合格 | **2 回** | 同じ Task の不合格の数（Task の `tries`） | 止めて Boss に報告する（Task そのものの見直しが必要なことが多い） |
| Done Gate の差し戻し | 8 回（Claude Code の決まり） | Done Gate に通らず、続けさせた数 | Claude Code が終了させる。Orchestrator は失敗として数える |
| 月の予算（全体） | （未決） | お金がかかる操作の合計。Approval Record の「お金」から数える | 新しくお金のかかる操作を止め、Boss に報告 |
実際の上限は、Boss が確かめられる量です。Worker を増やしても、確認が追いつかなければ増やしません。

## 緊急停止

| 対象 | 方法 | 実行する人 |
|---|---|---|
| すべてのエージェント | 会話を閉じる。`~/.claude/settings.json` の `deny` に `"Bash"` と `"Edit"` を足す | Boss || お金 | （未決。例：支払い手段を止める） | Boss |

緊急停止をしたら、Orchestrator が ADR に記録します。
